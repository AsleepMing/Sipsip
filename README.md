## 项目简介

Sipsip 是一个基于 Tauri + Rust + React 的桌面剪贴板管理工具，面向高频日常使用场景。所有剪贴板数据本地存储，支持快速搜索、标签整理、便捷粘贴，并提供日常 / 工作双模式隔离，让临时工作内容与日常剪贴板互不干扰。

## v1.0.4 补丁发布

v1.0.4 是一次补丁发布，重点是对上一轮标签筛选、类型筛选、搜索与删除维护内容做完整回归确认，并同步所有版本元数据。

### 🏷️ 标签筛选清理

标签点击现在使用独立的 `tagFilter` 状态，不再往搜索框里写 `tag:` 内部指令词，搜索框保持干净。

### 🔍 搜索与类型筛选

后端搜索接口新增 `content_type` 参数支持，富文本/图片/文件等类型筛选现在在 SQL 查询层完成，不再只依赖前端有限结果集做二次过滤。Header 新增显式"清除筛选"按钮和"全部"类型选项。

### 🗑️ 安全标签删除

全局标签删除只移除标签关联关系并刷新条目标签 JSON，不会误删剪贴板条目本身。

### 🌐 序号范围删除国际化

序号范围输入支持 `3-10`、`3到10`、`3至10` 和单个序号等多种格式。

### 🗣️ 语言一致性

`zh`、`en`、`tw` 三套翻译 key 完全对齐（522 个 key）。

### 📦 Windows portable 包

新增 `Sipsip-v1.0.4-windows-portable.zip` 免安装便携包。

## v1.0.6 修复

v1.0.6 修复了工作模式下置顶条目过一段时间后看起来自动取消置顶的问题。

- 重复内容合并/再次复制同内容时会保留已有记录的置顶状态、置顶顺序和标签。
- 关闭持久化存储时，工作模式中已置顶或带标签的记录仍会优先复用数据库保护记录，不会被新的未置顶会话记录覆盖。
- 置顶命令现在返回后端真实条目，并在数据库未实际更新时返回错误，避免“界面显示成功但刷新后消失”的假状态。

## v1.0.6 修复：工作模式置顶状态丢失

v1.0.6 修复了工作模式下置顶项在重复内容刷新或后续剪贴板捕获后丢失置顶状态的问题。

- 重复内容处理复用已有数据库行时，保留原有的 `is_pinned`、`pinned_order` 和标签。
- 即使关闭了持久化存储，工作模式下的置顶/带标签记录仍会复用受保护的数据库行。
- `toggle_clipboard_pin` 现在返回后端完整的剪贴板条目，前端基于持久化状态更新而非乐观本地猜测。
- 统一了前端剪贴板排序逻辑：事件插入、过滤、置顶切换、拖拽重排全部遵循同一套置顶顺序规则。
- 置顶更新和已有行保存增加了影响行数检查，避免假成功 UI 状态。
- 非持久化会话裁剪优先移除普通临时项，保护置顶/带标签记录。

## v1.0.5 修复

v1.0.5 修复了富文本类别下按可见序号范围删除后“显示删除但仍在列表中”的问题。

- 普通历史分页查询现在正确向 Tauri 后端发送 `contentType`，富文本/类型筛选会在 SQL 层完成分页。
- 删除命令增加数据库影响行数检查，避免未来出现“调用成功但实际未删行”的假成功。
- 已确认实际数据库完整性正常，问题不是数据库损坏。

## v1.0.3 新增功能

### 🚀 批量删除性能优化

之前按序号范围删除（如 `13-121`）会逐条并发调用后端删除接口，每条删除都触发一次 UI 刷新，导致界面卡顿。

现在改为**单次批量调用** `delete_clipboard_entries(ids)`，后端一次性完成去重、跳过置顶、按条目真实模式删除，并只发出一次 `clipboard-changed` 事件。前端额外增加了 **80ms 防抖合并**，即使短时间内收到大量刷新事件，也只会触发一次 UI 更新。

### 🎯 输入弹窗焦点修复

Windows 下点击序号范围输入框后，之前会出现系统提示音且无法输入——原因是弹窗输入框没有正确获取 Tauri 主窗口焦点。

修复后，输入框在自动聚焦、鼠标按下和 focus 时都会调用 `activate_window_focus`，同时阻止 keydown 事件冒泡到全局键盘导航，确保输入体验流畅。

### 🔒 工作模式隔离进一步完善

v1.0.0 引入的日常 / 工作双模式在 v1.0.3 中进一步加固了隔离边界：

- **实时事件隔离**：`clipboard-updated` 事件携带的 `clipboard_mode` 必须匹配当前模式才插入列表，避免另一模式的新复制内容短暂闪入。
- **会话历史隔离**：非持久化的 `SessionHistory` 也按模式过滤，关闭持久化时不会出现跨模式缓存污染。
- **删除路径隔离**：工作模式下的删除、清空、最近清理、粘贴后删除、持久化限额淘汰全部走**无云同步 tombstone** 路径，确保工作内容不会通过云同步泄露。
- **远端删除安全**：云同步远端删除只影响日常模式记录，不会误删工作模式中的同内容条目。

## v1.0.0 核心功能

### 📋 日常 / 工作模式

在首页 Header 提供分段切换按钮，一键切换日常模式和工作模式：

- **日常模式**：常规剪贴板历史，支持云同步。
- **工作模式**：临时本地内容隔离区，默认不参与云同步。退出工作模式时可选择保留或清理工作缓存，清理时不写入云同步删除标记。

### 🏷️ 可见序号与范围删除

- 剪贴板列表每条记录旁显示**可见序号**，序号基于当前过滤、搜索、置顶排序后的实际显示顺序计算。
- 支持按序号范围删除，例如输入 `3-10` 删除第 3 到第 10 条可见记录。
- 输入框使用应用主题化弹窗，不再使用浏览器原生输入框。
- 置顶记录在范围删除中受保护，不会被误删。

### ⏱️ 最近时间范围清理

一键清理当前模式下指定时间范围内的剪贴记录：

- 清理最近 **1 小时**
- 清理最近 **24 小时**
- 清理完成后刷新历史列表，日常模式下自动触发云同步请求

### 📝 片段管理

- 将常用文本保存为**可复用片段**，支持分类和标签管理。
- 从剪贴板历史一键"转为片段"，或在片段面板手动创建。
- 片段支持搜索（标题、内容、分类、标签）、直接复制或粘贴到当前窗口。
- 使用次数自动统计，方便找到最常用的片段。

### 🔍 基础能力

- 本地优先的剪贴板历史：文本、富文本、图片、文件
- 快速搜索、标签管理、置顶和顺序粘贴工作流
- 可选的局域网文件传输（基于 Axum HTTP 服务器 + WebSocket）
- WebDAV / MQTT 跨设备同步路径
- 敏感信息预览脱敏
- 多套桌面主题和界面效果

## 本地开发

```bash
npm install
npm run tauri:dev
```

前端生产构建：

```bash
npm run build
```

桌面 release 构建：

```bash
npm run tauri:build
```

在当前 bundle 配置下，Windows 会生成 release 可执行文件：

```text
src-tauri/target/release/sipsip.exe
```

当前 Windows 便携包输出位置：

```text
dist/release/Sipsip-v1.0.6-windows-portable.zip
```

## 独立发布前配置

准备发布到你自己的 GitHub 前，建议先检查：

- `.env.example`
- `src/shared/config/brand.ts`
- `src-tauri/tauri.conf.json`
- `docs/releases/v1.0.6.md`
- `docs/releases/v1.0.6.md`
- `docs/releases/v1.0.5.md`
- `docs/releases/v1.0.4.md`
- `docs/releases/v1.0.3.md`
- `docs/releases/v1.0.0.md`

推荐做法：

- 在本地 `.env` 中填写 `VITE_APP_GITHUB_URL`、`VITE_APP_WEBSITE_URL`、`VITE_FEEDBACK_EMAIL`。
- 在自己的更新端点准备好之前，保持 `VITE_ENABLE_UPDATER=false`。
- 只有在确实需要远程服务时，再配置 `VITE_ANNOUNCEMENT_PING_URL` 和 `VITE_THEME_STORE_API_BASE`。
- 如果需要 Windows 安装包或更多平台安装器，继续调整 Tauri bundle targets。

## 说明

- 仓库保留了对旧 `TieZ` 安装和数据目录的兼容清理逻辑，方便现有本地数据迁移到 Sipsip。
- 工作模式主要用于临时本地内容；置顶或带标签记录仍受清理保护，除非后续单独增加危险确认。
