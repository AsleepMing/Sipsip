## 项目简介

Sipsip 是一个基于 Tauri + Rust + React 的桌面剪贴板管理工具，面向高频日常使用场景。所有剪贴板数据本地存储，支持快速搜索、标签整理、便捷粘贴，并提供日常 / 工作双模式隔离，让临时工作内容与日常剪贴板互不干扰。

## 最新版本：v1.0.6

v1.0.6 修复了工作模式下置顶条目在重复内容刷新后丢失置顶状态的问题。

- 重复内容合并 / 再次复制同内容时保留已有记录的 `is_pinned`、`pinned_order` 和标签。
- 关闭持久化存储时，已置顶或带标签的工作模式记录仍会复用数据库保护记录，不会被新的未置顶会话记录覆盖。
- `toggle_clipboard_pin` 返回后端真实条目，数据库未实际更新时返回错误，避免"界面显示成功但刷新后消失"的假状态。
- 统一了前端剪贴板排序逻辑：事件插入、过滤、置顶切换、拖拽重排全部遵循同一套置顶顺序规则。
- 非持久化会话裁剪优先移除普通临时项，保护置顶 / 带标签记录。

## 核心功能

### 📋 日常 / 工作模式

在首页 Header 提供分段切换按钮，一键切换日常模式和工作模式：

- **日常模式**：常规剪贴板历史，支持云同步。
- **工作模式**：临时本地内容隔离区，默认不参与云同步。退出工作模式时可选择保留或清理工作缓存，清理时不写入云同步删除标记。

### 🏷️ 可见序号与范围删除

- 剪贴板列表每条记录旁显示**可见序号**，序号基于当前过滤、搜索、置顶排序后的实际显示顺序计算。
- 支持按序号范围删除，例如输入 `3-10`、`3到10`、`3至10` 或单个序号。
- 输入框使用应用主题化弹窗，置顶记录在范围删除中受保护。

### ⏱️ 最近时间范围清理

一键清理当前模式下最近 **1 小时**或 **24 小时**的剪贴记录，清理完成后自动刷新历史列表。

### 📝 片段管理

将常用文本保存为可复用片段，支持分类、标签、搜索（标题 / 内容 / 分类 / 标签）、直接复制或粘贴到当前窗口，使用次数自动统计。

### 🔍 基础能力

- 本地优先的剪贴板历史：文本、富文本、图片、文件
- 快速搜索、标签管理、置顶和顺序粘贴工作流
- 可选的局域网文件传输（基于 Axum HTTP 服务器 + WebSocket）
- WebDAV / MQTT 跨设备同步路径
- 敏感信息预览脱敏、多套桌面主题

## 本地开发

```bash
npm install
npm run tauri:dev
```

前端生产构建：

```bash
npm run build
```

桌面 release 构建：

```bash
npm run tauri:build
```

Windows 产出：

```
src-tauri/target/release/sipsip.exe
dist/release/Sipsip-v1.0.6-windows-portable.zip
```

## 独立发布前配置

准备发布到你自己的 GitHub 前，建议先检查：

- `.env.example`
- `src/shared/config/brand.ts`
- `src-tauri/tauri.conf.json`

推荐做法：

- 在本地 `.env` 中填写 `VITE_APP_GITHUB_URL`、`VITE_APP_WEBSITE_URL`、`VITE_FEEDBACK_EMAIL`。
- 在自己的更新端点准备好之前，保持 `VITE_ENABLE_UPDATER=false`。
- 只有在确实需要远程服务时，再配置 `VITE_ANNOUNCEMENT_PING_URL` 和 `VITE_THEME_STORE_API_BASE`。

## 说明

- 仓库保留了对旧 `TieZ` 安装和数据目录的兼容清理逻辑，方便现有本地数据迁移到 Sipsip。
- 工作模式主要用于临时本地内容；置顶或带标签记录仍受清理保护，除非后续单独增加危险确认。
