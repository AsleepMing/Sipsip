# Sipsip v1.0.5 Release Notes

Release date: 2026-06-22

Sipsip `v1.0.5` is a patch release that fixes rich-text category range deletion after `v1.0.4`.

## Short GitHub Release Description

Sipsip v1.0.5 fixes rich-text category visible-index deletion by sending the correct Tauri `contentType` parameter for backend-filtered history pagination.

## Fixes

- Fixed `get_clipboard_history` frontend arguments from `content_type` to `contentType`.
- Added a shared `buildGetClipboardHistoryParams` helper so Tauri history query parameters are defined in one place.
- Added a frontend regression test for `rich_text` history query parameters.
- Added backend delete row-count checks to prevent false-success deletes.
- Added a Rust repository regression test covering rich-text filtering and deletion.

## Root Cause

`search_clipboard_history` correctly sent `contentType`, but normal paginated history fetch sent `content_type`. Because Tauri command arguments map frontend camelCase to Rust snake_case, the backend received no content-type filter for ordinary pagination.

The rich-text category was therefore built from mixed history pages and filtered locally. After range deletion, refreshed mixed pages could bring in other rich-text items, making the operation look like it succeeded but did not change the category view as expected.
