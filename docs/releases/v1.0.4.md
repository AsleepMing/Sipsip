# Sipsip v1.0.4 Release Notes

Release date: 2026-06-22

Sipsip `v1.0.4` is a patch release that confirms the tag filtering, content-type filtering, search, and deletion fixes from the previous maintenance pass, with version metadata aligned for release.

## Short GitHub Release Description

Sipsip v1.0.4 verifies the tag/search/delete maintenance fixes, aligns version metadata, adds language-key consistency cleanup, and provides a Windows portable package.

## Highlights

- **Tag filter cleanup**: Tag clicks use an independent `tagFilter` state instead of writing internal `tag:` tokens into the visible search box.
- **Search and type filtering**: Backend search accepts `content_type`, so type filtering is applied at the query layer instead of only after a limited frontend result set.
- **Clear filter UX**: The header provides an explicit clear-search action and an "All" content-type option.
- **Safe tag deletion**: Global tag deletion removes tag relationships and refreshes item tag JSON without deleting clipboard entries.
- **Visible-index deletion**: Index-range deletion supports formats such as `3-10`, `3到10`, `3至10`, and single visible indexes.
- **Language consistency**: `zh`, `en`, and `tw` translation key sets are aligned.

## Installer Note

`npx tauri build --bundles nsis` reached the release build step successfully, but the NSIS packaging step could not download Tauri's `nsis-3.11.zip` toolchain because the current environment could not connect to `github.com:443`. The portable zip is the current Windows distributable package.
